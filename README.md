# Штаб пятиклассника

Переносимый прототип личного игрового центра управления школьным днём.

## Как запустить

Откройте `index.html` в браузере. Установка, сервер и интернет не нужны.

Прогресс рюкзака, опыт и состояние кнопки «Начать день» сохраняются в `localStorage` браузера.

## Что лежит в архиве

- `index.html` — самостоятельный адаптивный интерактивный прототип;
- `PROJECT_BRIEF.md` — полное описание продукта, функций, дизайна и следующих этапов;
- `README.md` — этот файл.

## Как продолжить в новом проекте

Передайте новому Codex-проекту всю папку и попросите прочитать `PROJECT_BRIEF.md`. В конце документа есть готовый стартовый промпт.
